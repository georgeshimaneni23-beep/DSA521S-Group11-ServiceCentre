===============================================================
  TASK A5 - DATA-STRUCTURE JUSTIFICATION
===============================================================
QUEUE (waiting line)
  Students must be helped in the order they arrived. A queue removes only
  from the front and adds only at the rear, so the arrival order is enforced
  by the structure itself and cannot be broken by mistake. Both operations
  are O(1), so a busy queue never slows the program down.

SINGLY LINKED LIST (service records)
  The number of records for a day is not known in advance and records are
  inserted and removed in the middle. A linked list grows one node at a time
  and a deletion only requires re-pointing one next reference - O(1) once the
  node is located - whereas an array would need every later element shifted.

STACK (postfix evaluation)
  In a postfix expression, the operands an operator needs are always the two
  most recently produced values. That is exactly last-in-first-out behaviour,
  so push() and pop() give the right operands automatically with no searching.

ARRAY (daily statistics)
  The statistics pass over a fixed set of completed service times and never
  insert in the middle. An array stores the values contiguously with O(1)
  index access, which makes a single traversal for total, average, highest,
  lowest and the over-10-minute count both simple and cache-friendly. It is
  also the natural input form for the sorting algorithms in Part B.
